# PixVerse Video API & Web Studio

API REST professionnelle d'intégration PixVerse pour la génération vidéo AI (Text-to-Video, Image-to-Video) avec un Studio Web et un module Goat Bot V2.

## 🚀 Installation & Lancement

```bash
# Installation des dépendances
npm install

# Lancement en développement
npm run dev

# Lancement en production
npm start
